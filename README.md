# Bariatric Insurance Navigator v13

Browser-based Streamlit prototype for pre-consult bariatric insurance criteria gathering.

## Demo-safe improvements in v13
- Professional landing page
- Persistent **PROTOTYPE DEMO — DO NOT ENTER PHI** warning
- Blank-demo workflow button
- One-click fictional sample test case
- Sidebar navigation
- Existing chart PDF option retained
- Streamlit Cloud-ready project structure
- Dockerfile for IT/cloud deployment
- Deployment guide for demo hosting and Banner-approved production planning

## Run locally
From this folder:

    python -m pip install -r requirements.txt
    python -m streamlit run app.py

Then open the local Streamlit address shown in the terminal, typically:
    http://localhost:8501
